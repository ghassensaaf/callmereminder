# DialCues Roadmap

Product vision and phased evolution of DialCues.

---

## Current State (Phase 0)

- Sign up / authentication
- Configure call settings (Vapi API key, phone number ID)
- Create one-time reminders
- AI phone calls at scheduled time

---

## Phase 1: Reliability & Usability

- **Recurring reminders** — Daily, weekly, or custom schedules
- **Reminder history** — View past reminders (completed, failed) with details
- **Better scheduling management** — Quick presets (e.g. "In 15 min"), snooze/reschedule, timezone improvements

---

## Phase 2: Hosted Experience

- **Hosted phone numbers** — DialCues provides phone numbers; users no longer need Vapi
- **Subscription plans** — Free tier limits, paid plans for unlimited/hosted usage
- **Simplified onboarding** — No external API configuration required

---

## Phase 3: Developer Platform

- **Public API** — REST/GraphQL endpoints for third-party apps
- **Programmatic reminder management** — Create, update, delete reminders via API
- **API keys / OAuth** — Authentication for external integrations
